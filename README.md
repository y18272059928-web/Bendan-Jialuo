# 笨蛋珈珞

面向武汉大学研究生个人使用的离线优先 Android 课表。目标是通过校内统一身份认证导入课表，并提供今日课程、周课表、每日摘要和课前提醒。

> **非官方应用：** 本项目与武汉大学官方无隶属或合作关系，仅供个人学习与课表管理。学校门户调整后，导入功能可能需要同步适配。请始终只在 `whu.edu.cn` 及其子域的 HTTPS 页面中登录，不要向开发者或其他人提供账号、密码、Cookie 或 Token。

## 获取应用

普通使用者可在 GitHub 仓库的 Releases 页面下载最新版 `app-release.apk`。Android 首次侧载时可能需要允许浏览器或文件管理器“安装未知应用”。升级时直接安装新版即可保留本地课表；建议升级前确认安装包来自本仓库。

## 当前状态

- 原生 Kotlin + Jetpack Compose 工程
- Android 8.0+，以 API 37 编译并面向 API 37
- SQLite 本地课表
- 教学周、单双周和课程日期计算
- 今日页与七天 × 13 节响应式单页彩色块状周课表，无需横向或纵向滑动
- 点击今日卡片或周课表课程块可编辑课程，支持手动新增、修改和删除
- 可修改课程名、教师、教室、星期、节次、周次，并添加个人备注
- 每门课程可选择“正常 / 考试周 / 已结课”标识；已结课课程保留显示但停止提醒
- “今天 / 周课表 / 我的”三栏导航，导入与设置集中在“我的”
- 固定浅米色、暖棕色舒适主题
- 每日 07:30 摘要与课前 15 分钟提醒
- 课前提醒按未来 6 周滚动登记，并随每日摘要续订到整个学期结束
- “我的”页显示通知和精确闹钟权限状态，误拒通知后可直接重新授权
- 重启、时间和时区变化后恢复提醒
- 重新从门户导入同名课程时保留用户填写的备注与课程标识
- 通过智慧珞珈移动版或电脑版首页的同源官方 HTTPS 课表接口导入，无需打开白屏的应用/课表详情页
- 自动遍历全部教学周并合并课程周次；同时保留课表相关 XHR/JSON 与页面表格的兼容解析
- 导入前预览、事务覆盖、导入后立即清除网页登录状态
- 设置页可校准第 1 周日期与教学周数

首次启动会显示两门明确标注的演示课程；真实导入成功后会整体替换。

## 构建

开发环境需要 JDK 17、Android SDK 37 和网络可用的 Gradle 依赖源。可直接使用 Android Studio 打开项目，也可以配置 `JAVA_HOME`、`ANDROID_SDK_ROOT` 后运行：

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

本项目原始开发环境的工具和缓存固定在项目 `.tools/`，避免占用 C 盘；该目录不会提交到 Git。工具已准备好时也可使用：

```powershell
.\scripts\build-debug.ps1
```

APK 输出到 `app\build\outputs\apk\debug\app-debug.apk`。

用于实体手机试用时，建议构建关闭 WebView 调试的个人预览版：

```powershell
.\scripts\build-release.ps1
```

输出为 `app\build\outputs\apk\release\app-release.apk`。它目前使用本机 Android Debug 证书签名，仅供个人侧载测试，不用于应用商店发布。

## 手机试用

1. 将 `app-release.apk` 传到 Android 8.0 或更高版本手机并安装。
2. 首次启动允许通知；在“我的 → 提醒”中按提示开启精确提醒权限。
3. 打开“我的”，点击“从智慧珞珈导入课表”，在武大网页中亲自登录，停留在显示当前教学周的智慧珞珈首页；移动版或电脑版均可，无需点击“应用”“查看更多”或“研究生综合服务”。
4. 点击“导入门户课表”，等待应用读取并合并全部教学周，然后核对课程数、首周日期和课程名称，再确认导入。
5. 若学期名显示“首周待确认”，在“我的 → 学期校准”中调整或确认日期；为避免错时通知，校准完成前不会启用课程提醒。
6. 在“周课表”点“添加课程”，或点击任一彩色课程块进行修改；“我的 → 手动添加课程”也可进入编辑器。

若未识别到课程，本机演示/原课表不会被覆盖，按 `docs/CAPTURE_GUIDE.md` 提供脱敏字段结构即可继续适配。

## 隐私

课表只保存在设备本地，系统云备份也被禁用。登录由武大网页完成；导入 WebView 禁用表单保存、自动填充和视图状态保存，应用不保存学号、密码或验证码。课表候选响应只在 WebView 内存中短暂保留，退出导入页或确认导入后会清除网页登录数据。任何用于进一步适配的私有响应必须放入已忽略的 `captures/private/`。
