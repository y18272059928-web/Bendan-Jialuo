## 📥 下载

在 [Releases](https://github.com/y18272059928-web/Bendan-Jialuo/releases/latest) 下载最新版 `app-release.apk`。

首次安装时，Android 可能会提示允许浏览器或文件管理器“安装未知应用”。以后直接覆盖安装新版即可，已经保存在本机的课表不会消失。

## 为什么做这个

智慧珞珈里的研究生课表查看起来不太顺手，市面上的课表软件又经常无法直接导入。于是有了“笨蛋珈珞”：不做复杂的校园门户，只想把每天上什么课这件事变得简单一点。

## ✨ 现在能做什么

### 一页看完整周课表

- 周一到周日、每天 13 节课都放在同一页，无需在课表内部上下或左右滚动
- 整张课表左右滑动即可像日历一样切换周次，也保留了左右箭头
- 查看其他周时，点击顶部日期可以马上回到本周
- 点击彩色课程块即可编辑课程

### 今日课程与提醒

- “今天”页面按时间列出当天课程
- 每天 07:30 汇总当天课表
- 每节课开始前 15 分钟提醒
- 手机重启、修改时间或切换时区后会自动恢复提醒
- “已结课”的课程仍会留在课表里，但不再发送通知

### 手动添加和修改

可以随时新增、修改或删除课程，包括：

- 课程名称、任课教师和教室
- 星期、开始节次和结束节次
- 任意选择上课周次，也可以快速选择全部、单周或双周
- 个人备注
- “正常 / 考试周 / 已结课”标识

在“周课表”点击课程块，或从“我的 → 手动添加课程”进入编辑器。

### 从智慧珞珈导入

- 登录始终在武汉大学网页中完成，应用不读取或保存学号、密码和验证码
- 停留在智慧珞珈移动版或电脑版首页即可导入，不需要进入容易白屏的“应用”或“查看更多”
- 自动读取并合并各教学周的课程和周次
- 导入前先显示预览，确认后才替换本机课表
- 导入失败不会动原来的课表
- 重新导入同名课程时会保留自己填写的备注和课程标识
- 退出导入页后会清除 Cookie、网页缓存和历史记录

## 🚀 第一次使用

1. 安装 APK，首次启动时允许通知。
2. 打开“我的 → 提醒”，按提示开启精确提醒权限。
3. 点击“从智慧珞珈导入课表”，在打开的武大页面中亲自完成登录。
4. 回到显示当前教学周的智慧珞珈首页，点击“导入门户课表”。
5. 核对预览中的课程数、首周日期和课程名称，再确认导入。
6. 如果学期名称带有“首周待确认”，在“我的 → 学期校准”中调整或确认第一周日期。

首次启动会看到两门明确标注的演示课程，成功导入真实课表后会整体替换。

如果没有识别到课程，可以阅读 [脱敏采集指南](docs/CAPTURE_GUIDE.md)。请勿提交包含姓名、学号、Cookie、Token 或真实课程信息的文件。

## 🔒 数据与隐私

- 课表、备注和设置只保存在手机本地 SQLite 数据库
- 已禁用 Android 系统云备份
- 导入页面禁用表单保存、自动填充和视图状态保存
- 课表候选响应只在导入页面内存中短暂存在
- 应用不包含自建服务器，也不会把课表上传给开发者

更完整的边界说明见 [项目架构](docs/ARCHITECTURE.md)。

## 🧱 技术栈

| 用途 | 方案 |
| --- | --- |
| 语言与界面 | Kotlin + Jetpack Compose + Material 3 |
| 本地存储 | Android SQLite |
| 网页导入 | Android WebView，仅允许受信任的 HTTPS 会话跳转 |
| 时间计算 | `java.time`，支持教学周、单双周和指定日期课程计算 |
| 通知 | AlarmManager + 本地通知 |
| 最低系统 | Android 8.0（API 26） |
| 编译目标 | Android API 37 |

## 🛠️ 本地构建

需要 JDK 17、Android SDK 37 和可用的 Gradle 依赖源。使用 Android Studio 打开项目，或者在 PowerShell 中运行：

```powershell
.\gradlew.bat testDebugUnitTest lintRelease assembleRelease
```

如果已经准备好项目内的 E 盘开发环境，也可以运行：

```powershell
.\scripts\build-release.ps1
```

APK 输出到：

```text
app\build\outputs\apk\release\app-release.apk
```

当前 Release 使用 Android Debug 证书签名，适合个人侧载和同学试用，不用于应用商店正式发布。

## ⚠️ 目前的限制

- 智慧珞珈网页或接口调整后，导入功能可能需要跟着适配
- 每日摘要时间和课前提醒分钟数暂时固定
- 重新导入会替换当前课表；确认前请仔细检查预览
- 不同手机厂商可能会限制后台提醒，需要允许应用后台运行
