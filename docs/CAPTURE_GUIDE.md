# 研究生课表接口取样指南

应用现已具备自适应识别能力。只有在手机内“识别当前课表”仍提示未识别时，才需要项目所有者在电脑浏览器中亲自完成以下兼容性取样；开发者不接触账号密码。

1. 打开 `https://my.whu.edu.cn/` 并登录。
2. 进入“研究生综合服务”中的个人课表页面。
3. 打开浏览器开发者工具的 Network，筛选 `Fetch/XHR`。
4. 刷新或切换一次学期，定位返回课表数据的请求。
5. 仅保存响应正文的脱敏副本到 `captures/private/`。
6. 删除 Cookie、Authorization、Token、学号、姓名和实际课程名称等信息；保留 JSON 字段结构、周次和节次格式。

如果课表没有 XHR 请求，则保存课表区域的脱敏 HTML。不要导出或提交完整 HAR。
