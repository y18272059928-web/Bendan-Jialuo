# 阶段状态（2026-09-18）

当前版本：`0.5.0`（新增考试、待办、停课日、主题切换与应用内更新检查）。

## 已完成

- 今日课程与七天 × 13 节时间轴彩色块状周课表；整页左右滑动切换周次，七列与 13 行始终一页完整显示。
- 课程可手动新增、修改、删除，支持备注和“正常 / 考试周 / 已结课”标识。
- “我的 → 学业计划”可新增、修改和删除考试，记录时间、地点、座位、关联课程与备注。
- 待办支持课程关联、截止时间、三档提前提醒、完成与恢复；逾期待办和未来七天考试会显示在“今天”页。
- 可添加节假日或临时停课日；指定日期自动跳过课程、每日摘要、课前提醒和后续系统日历同步。
- SQLite v3 新增考试、待办、停课日表，由 v1/v2 原地升级，不删除旧课表。
- 删除课程最后一条上课安排时，关联的考试和待办会保留并解除课程关联。
- 重新导入同名课程时保留备注、标识、考试、待办和停课日，并自动重映射课程关联。
- 考试默认提前一天提醒；待办按项目选择提前 15 分钟、1 小时或 1 天提醒。
- 课程首周待确认时仅暂停课程类通知，考试和待办仍可正常提醒。
- 通知、精确闹钟、系统日历同步、开机与时区变化后的恢复均已接入。
- 提供暖米色、青茶色和樱花色三套固定浅色主题，选择保存在手机本地。
- 应用内可手动检查 GitHub Releases；只在点击时联网，只打开 GitHub HTTPS 发布页。
- 智慧珞珈登录仍只发生在学校 HTTPS 页面，应用不保存账号、密码、Cookie 或 Token。
- JDK、Gradle、Android SDK 和缓存全部位于项目 E 盘 `.tools/`。
- Release 编译、29 项单元测试和 Android Lint 均已通过。

## 尚需项目所有者参与一次的事项

课表必须登录后才能读取。项目所有者只需在实体手机内亲自登录，停留在显示当前教学周的智慧珞珈首页并点击“导入门户课表”；不得提供账号密码、Cookie、Token 或完整 HAR。

实体手机建议重点确认：

1. 新增考试和待办后，编辑、完成与删除是否符合使用习惯。
2. 添加当天停课日后，“今天”页是否显示停课原因。
3. 三套主题在手机字体大小与显示缩放设置下是否舒适。
4. 考试、待办、课前提醒和系统日历通知是否均未被厂商省电策略拦截。
5. “检查 GitHub 更新”能否打开新版本 Release 页面。

## 已知限制

- 每日摘要时间和课程课前分钟数暂为固定值；待办提醒提供三档选择。
- 系统日历提醒仍取决于手机自带日历应用的通知设置。
- 当前主机没有连接 Android 实体设备，最终触控与视觉体验仍以手机安装测试为准。
- Release 暂用 Debug 证书签名；如果以后要上架，需要换成长期保管的正式签名证书。
