# 阶段状态（2026-09-10）

当前版本：`0.3.0`（新增七天时间轴彩色块状周课表、完整手动课程编辑、备注和“正常 / 考试周 / 已结课”标识）。

## 已完成

- 从空目录建立原生 Android 工程。
- 今日课程与可前后翻周的七天 × 13 节时间轴彩色块状周课表。
- 今日课程卡片和周课表彩色块均可点击编辑。
- 可手动新增、修改和删除上课安排，编辑课程名、教师、教室、星期、节次与逐周周次。
- 支持个人备注与“正常 / 考试周 / 已结课”课程标识，并在今日页和周课表清晰展示。
- 已结课课程仍保存在课表中，但不进入每日摘要和课前提醒。
- 固定浅米色、暖棕色视觉主题，不随系统深色模式切换为黑色。
- 底部导航精简为“今天 / 周课表 / 我的”，导入、提醒权限、学期校准与隐私说明集中在“我的”。
- SQLite v2 本地数据库，课程、上课安排、周次集合、备注和标识模型；从 v1 无损升级。
- 重新导入同名课程时保留用户备注与标识。
- 教学周、单双周和指定日期课程计算。
- 每日 07:30 摘要、课前 15 分钟提醒。
- 课前闹钟按未来 6 周滚动登记，每日 07:30 自动续订，避免大量课程挤掉学期后段提醒。
- 每日摘要限定在学期日期范围内，避免开学前或结课后持续发送“没有课程”。
- 精确闹钟降级、通知权限、开机/改时间/改时区/升级后恢复。
- “我的”页分别显示通知权限与精确闹钟权限，授权成功后自动重建提醒。
- 重导课表时取消旧课程闹钟，避免幽灵提醒。
- 从武大 HTTPS 门户起始、仅信任其会话内 HTTPS 跳转的 WebView；禁用表单保存、自动填充和视图状态保存，并支持主动清除登录状态。
- 不伪装官方智慧珞珈客户端；接受学校按手机环境分流到移动首页。
- 在移动版或电脑版首页直接调用同源 `/whdxIndex/getCurriculum?date=...` HTTPS 接口，自动遍历教学周并合并精确周次，无需打开“应用”或“查看更多”。
- 不放开旧研究生系统的 HTTP 降级跳转，避免会话票据或课表数据通过明文连接传输。
- 将 `jsbridge://NotificationReady` 和页面通知回调作为无返回值的移动页通知安全忽略，其他非 HTTPS 桥接协议仍不执行。
- 支持门户新窗口、跨域 SSO、第三方 Cookie，并显示当前域名、加载进度和 HTTP 错误。
- 课表相关 XHR/JSON 内存捕获与页面表格双路径识别。
- 常见中英文字段、周次区间、单双周、星期和节次自适应解析。
- 导入预览与覆盖确认；失败时不会改动原课表。
- 学期首周和总周数可在设置页校准，调整后自动重建提醒。
- JDK、Gradle、Android SDK 和缓存全部放在 E 盘项目 `.tools/`。
- Debug 与个人预览版 APK 构建成功，21 个领域、编辑、提醒规划与导入器单元测试通过。
- APK Signature Scheme v2 签名校验通过（当前为本地 Debug 签名）。
- Android Lint 通过：0 errors；仅保留与 AGP 9.4 官方配套 Gradle 版本相关的升级提示。

## 尚需项目所有者参与一次的事项

课表必须登录后才能读取。项目所有者只需在实体手机内亲自登录一次，停留在显示当前教学周的智慧珞珈首页并点击“导入门户课表”；不得提供账号密码、Cookie、Token 或完整 HAR。

若自适应识别未覆盖学校当前字段，再按 `docs/CAPTURE_GUIDE.md` 提供脱敏结构。之后需要完成：

1. 扩展少量真实字段别名。
2. 使用真实课表验证周次、节次、跨周和教室字段。
3. 在实体手机验证通知、锁屏和厂商后台限制。

## 已知限制

- 当前内置的是明确标识的演示课表，且不会安排演示提醒。
- 每日摘要和课前分钟数暂为固定值。
- Android 模拟器与 API 36 镜像已安装在项目 E 盘工具目录；当前主机缺少系统级虚拟化驱动，纯软件模拟器首次启动过慢，已按项目所有者意见停止，因而新版 UI 的最终视觉确认仍以实体手机截图为准。
