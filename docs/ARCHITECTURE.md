# 笨蛋珈珞架构

## 目标

个人使用、离线优先的 Android 课表。统一身份认证始终发生在武大网页中；应用不采集或保存学号、密码和验证码。

## 模块边界

- `data`：SQLite 数据库和学期、课程、上课安排、考试、待办、停课日模型。
- `domain`：教学周、课程实例日期、武大节次时间和课程增删改逻辑，不依赖 Android UI。
- `notification`：每日摘要、课前提醒、考试与待办提醒，以及开机和时区变化后的恢复。
- `calendar`：向系统 Calendar Provider 写入独立本地日历、课程事件和事件提醒。
- `importer`：武大研究生系统适配边界。认证留在 WebView，解析器只处理当前页面或脱敏接口响应。
- `ui`：Compose 今日页、时间轴块状周视图、课程编辑器、学业计划、导入页、主题与设置页。
- `update`：用户主动触发的 GitHub Releases 版本检查，不接触课表数据。

## 导入策略

1. WebView 仅允许 `whu.edu.cn` 及其子域名的主页面跳转。
2. 用户在学校页面中亲自登录并进入课表。
3. 仅在武大 HTTPS 页面加载开始时注入最小捕获脚本；它只在响应 URL/正文出现课表特征时，于 WebView 内存保留最多 6 份候选。
4. 优先解析课表 JSON/XHR；接口不可用时解析当前页面可见表格，不读取密码输入框值。
5. 自适应字段映射要求课程名、星期与节次同时成立，避免把门户中的无关信息误识别为课程。
6. 解析结果必须先预览，再以单个 SQLite 事务替换本学期数据。
7. 导入成功、主动退出或离开导入页后清除 Cookie、DOM Storage、缓存和 WebView，并重建未来提醒。

当前解析器覆盖常见的中文表头，以及 `KCMC/JSXM/JSMC/XQJ/KSJC/JSJC/ZCD`、`courseName/teacherName/weekDay/startSection` 等常见 JSON 字段。真实系统若使用不同字段，仍需一份脱敏结构扩展映射。不得提交 HAR、Cookie、Token、姓名、学号或实际课程信息到 Git。

## 本地编辑与兼容

- 数据库 v2 在课程表中新增备注和状态字段；v3 新增考试、待办和停课日表。旧版数据库原地升级，不删除已有课程。
- 一条课程可关联多条上课安排；删除最后一条安排时才清理孤立课程。
- 保存手动修改后立即重建通知计划；若用户已经启用系统日历同步，也会刷新整学期日历事件。
- 门户重新导入时，按标准化课程名保留已有备注和课程标识，并重映射考试、待办的课程关联；停课日保持不变。
- “已结课”只影响提醒，不删除课程记录，用户可随时恢复为“正常”。

## 提醒策略

- 每日 07:30 安排当天摘要。
- 默认课前 15 分钟提醒。
- 待办按项目选择的提前量提醒；考试默认提前一天提醒，若已不足一天则在考前两小时兜底。
- 课程首周尚未确认时只暂停课程类提醒，不影响考试与待办提醒。
- 有精确闹钟权限时使用精确闹钟，否则降级为允许休眠执行的普通闹钟。
- 课前提醒按未来 6 周滚动登记，并由每日摘要持续续订到学期结束。
- “我的”页显示已登记数量和下一次触发时间，并提供立即测试通知与一键重建。
- 第二层兜底把整学期课程写入独立系统日历，每个事件同样提前 15 分钟提醒。
- 系统日历只在用户明确授权并首次点击同步后启用；后续课表变更和应用启动时自动刷新。
- 已结课课程不登记课前提醒，也不进入每日摘要。
- 开机、改时间、改时区、应用升级或精确闹钟权限获批后重新安排。

## 安全约束

- 禁止明文 HTTP。
- 更新检查只在用户点击后访问固定 GitHub API，且只允许打开 `https://github.com/` Release 地址。
- WebView 禁止文件和 Content Provider 访问。
- 不使用 JavaScript bridge；候选响应留在 WebView 页面内存中，只在用户点击识别后通过一次性 `evaluateJavascript` 取回。
- 私有捕获文件只放 `captures/private/`，该目录已被 Git 忽略。
- 所有开发工具、SDK 和 Gradle 缓存位于项目 `.tools/`（E 盘）。
